RUN_TRACKER_

A run tracker for roguelites that logs itself. Point it at your save folder, play, and it detects when a run ends — then offers to log it.

Win/loss records, build tracking, win streaks, and a shareable profile. Cloud-synced across devices.

// FEATURES

Track every run without the busywork

Logging runs by hand gets old fast. RUN_TRACKER watches your save files and does the tedious part for you, so the archive stays complete.

◉

Automatic run detection

Connect a game's save folder and RUN_TRACKER polls it while you play. When a run ends, a toast pops up to quick-log it or review the details first.

▦

Stats that build themselves

Win rate, current streak, and best streak update as you log. Filter by win / loss / quit, and full-text search across notes, tags, and fields.

⚙

Build tracking

Save loadouts — items, bans, strategy, and your own custom fields — then see exactly which runs each build produced and how it performed.

⌁

Custom fields per game

Every game tracks different things. Toggle built-in fields (character, floor, score, seed, duration…) or add your own to match how you play.

☁

Cloud sync

Sign in and your archive follows you across devices. Log offline and it syncs when you reconnect — nothing gets lost.

⤳

Shareable profile

Generate a read-only link to show off your stats, games, and builds. Your private run notes stay private — they're never included in a share.

// WORKFLOW

Four steps, then it's automatic

Setup takes under a minute per game. After that you just play.

01

Add a game

Create a game and pick its type. RUN_TRACKER shows you exactly which save folder to point at.

02

Connect the folder

One click grants read access to that folder. The handle is remembered, so it reconnects on reload.

03

Play your run

When the save shows a run has ended, a toast offers to quick-log it or open it pre-filled for review.

04

Watch the stats grow

Win rate, streaks, and per-build performance update instantly and sync to the cloud.

// PRIVACY & SECURITY

Your archive, your data

Built to keep your data yours — verified with a penetration test, not just claimed.

  • [✓]
    Per-account isolation. Row-level security means no one can read or change another player's runs, games, or profile — enforced at the database, not just the UI.
  • [✓]
    Private notes stay private. Share links carry your stats, builds, and pictures — never your per-run notes or comments.
  • [✓]
    Read-only access to saves. Watchers only read your save files to detect a finished run. They never write to or modify your game.
  • [✓]
    No tracking, no ads. The app loads its own code and one trusted library (integrity-checked). That's it.
